## 镜像指纹

```
sources/<chip>/
  brom.bin       <大小> B
                 <SHA-256>
  brom.elf       <大小> B（可选）
                 <SHA-256>
  decompiled.c   <大小> B（可选）
                 <SHA-256>（<N> 个函数）
```

> 反编译结果的函数名通常是 `sub_XXXX`（`XXXX` = 函数地址）。
> **本文引用的每个 `sub_XXX` 都应该能在 `decompiled.c` 里直接搜到。**
